【一】定义

△₊ f(x) = ( f(x+a) − f(x) ) / a        （微观；宏观时为中心差分）
△₊₊(x) = ( f(x+2a) − 2f(x+a) + f(x) ) / a²
△₂ₓ₊ f(x,y) = ( f(x+a,y) − f(x,y) ) / a
△₂ᵧ₊ 同理；△₂ₓ₊₊ 省略
∑ f(x)a 是离散积分；当 a→0 退化为传统微积分
c = 1；a 取普朗克长度；aₜ 取普朗克时间
四维形上 N+a 或许为 a，故不存在边界

【二】散变量

kₓ、kᵧ、k_z、kₜ 为 a 在各轴上的变化，kⱼ ∈ C
k⁴ 为四方向综合变化，可写成 4×4 矩阵：
对角线 = 各方向的 k 值，非对角 = 方向间耦合
体积元：a³；带时间：k⁴a³(caₜ)

【三】引力

场方程：
    △₊₊(Z) = ∑ hₙ · k⁴ₙ · a⁴ = C
    hₙ = ᵪ ρₙ / b ，  b = △₊₊(x²/2) = 1 (1/L²)
    ᵪ = 8πG / c⁴ ，  C 单位 m⁴

物体在引力场中沿弯曲时空的测地线运动
（即 Z 空间中“顺着弯曲”的那条最短线；跳过时空的 s 部分暂不计入）

【四】Z 空间

Zₓ = ∑ kₓₙ a ，  kₓ = △₊ Zₓ
两点间最短线有两条（除绝对真空）：顺着弯曲的、跳过弯曲的 s
